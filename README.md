# Rock Paper Scissors Game 🎮

A simple and interactive **Rock Paper Scissors Game** built using HTML, CSS, and JavaScript. This project allows users to play against the computer by choosing rock, paper, or scissors. The computer randomly selects its move, and the game determines the winner based on the rules.

## ✨ Features
- 🪨 Rock, Paper, and Scissors selection with visual icons.
- 🤖 Random computer move generation.
- 🏆 Automatic winner determination.
- 📊 Real-time score tracking for the player and computer.
- 🎨 Interactive user interface with hover effects and dynamic result messages.
- 🔄 Instant gameplay without refreshing the page.

## 🛠️ Technologies Used
- **HTML5** – Structures the game interface.
- **CSS3** – Styles the layout, icons, scoreboard, and interactive elements.
- **JavaScript** – Handles game logic, random computer choices, score updates, and result messages.

## 📂 Project Structure
- `index.html` – Main webpage and game layout.
- `style.css` – Styling and visual design.
- `script.js` – Game logic and functionality.
- `rock.png` – Rock icon.
- `paper.png` – Paper icon.
- `scissors.png` – Scissors icon.

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click on rock, paper, or scissors to play against the computer.

## 🎯 Objective
The goal is to beat the computer by selecting the winning move:
- Rock beats scissors.
- Paper beats rock.
- Scissors beats paper.
